# Bus ticket Python Project
## Develop Branch 
-After final testing is done branch will be merged with the main branch 
### Overview
- This project is a Bus Ticket Management System written in Python. It allows users to purchase tickets, choose top-up options, and provides administrators with tools to manage ticket categories, top-ups, and track sales.
The develop branch is used for testing and integrating new features before merging them into the main branch.
## Features
### Guest Mode
- Browse ticket categories.
- Buy tickets from selected categories.
- Add multiple tickets to a basket.
- Add multiple top-ups to tickets.
- View basket with receipt and total price.
- Remove items from basket.
### Administrator Mode
- View all ticket categories.
- Add new categories with multiple randomized default top-ups.
- Remove categories and associated tickets.
- Edit ticket prices for any top-up.
- View saved purchases with:
Total tickets sold.
Total revenue (overall).
Tickets sold per type with revenue.
