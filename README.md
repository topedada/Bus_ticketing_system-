# Bus ticket Python Project
## Use case 1: Buying a ticket
### Actors:
- User
### Preconditions 
- User is logged in (or identified as guest)
### Trigger 
- Customer selects the option "Buy ticket"
### Main flow 
- Display ticket types
- User selectes a ticket
### Postconditions:
- Ticket is created and associated with customers
- Confirmation message is shown
